# 工具与数据源

工具只负责获取数据和提高执行效率，不能代替业务判断。使用任何工具时，都应记录数据时间、市场范围、平台口径和样本限制。

## 7. 工具评估维度

选择工具时建议比较：

- 数据覆盖范围
- 数据准确性和更新频率
- 国家、平台和品类覆盖
- 指标口径是否透明
- API 和导出能力
- 团队协作与权限
- 与现有系统的集成成本
- 价格和使用限制
- 数据安全、隐私和合规
- 供应商稳定性和退出成本

## 8. 数据使用检查清单

- [ ] 数据对应哪个国家、平台和时间范围？
- [ ] GMV、销量、广告等指标口径是否明确？
- [ ] 数据是估算、抓取还是平台官方数据？
- [ ] 是否存在抽样偏差、延迟或缺失？
- [ ] 是否能与内部订单和财务数据交叉验证？
- [ ] 工具排名是否被误当作市场因果结论？
- [ ] 报告中是否记录数据来源和查询日期？

## 9. 维护方式

工具能力和平台规则变化较快。本文件只维护稳定用途，不记录容易过时的套餐价格和按钮路径。具体操作说明可在 `99-resources` 下按工具单独建文件，并标记最近验证日期。
