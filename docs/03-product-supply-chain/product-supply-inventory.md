# 产品开发、供应链与库存经营

## 1. 模块目标

该模块负责把市场机会转化为可以稳定交付、具备利润空间的商品，并用合理库存支撑销售。核心不是“找到最低采购价”，而是在质量、成本、交期、库存和现金流之间取得平衡。

## 2. 产品开发流程

```text
用户与市场需求
→ 产品立项
→ 产品需求定义
→ 供应商寻源
→ 样品与成本评估
→ 功能/材质/包装改进
→ 认证与质量验证
→ 小批量试产
→ 上市测试
→ 正式量产
→ 生命周期迭代
```

## 3. 产品需求定义

产品需求文档至少应包含：

- 目标用户和使用场景
- 用户痛点与购买动机
- 核心功能和非功能要求
- 差异化卖点
- 目标价格和成本上限
- 材质、颜色、尺寸和外观要求
- 包装、配件和说明书
- 认证、法规和知识产权要求
- 质量标准和验收方法
- 预计销量、MOQ 和交期
- 图片、视频和 Listing 内容需求

铺货模式可直接采购成熟商品；品牌模式则需要通过功能、材质、包装、配件、品质、设计和服务形成差异化。

## 4. 供应商开发与评估

供应商来源可以包括 1688、Alibaba、产业带、展会、OEM、ODM 和现有供应商推荐。

| 评估维度 | 关注内容 |
|---|---|
| 价格 | 阶梯报价、模具、包装、认证和附加费用 |
| MOQ | 首单、补单、颜色和包装的最小起订量 |
| 交期 | 打样、生产、质检、出货和旺季产能 |
| 质量 | 合格率、质量体系、历史投诉和整改能力 |
| 研发 | ODM、结构、电子、包装和测试能力 |
| 认证 | 目标国家和平台所需认证 |
| 产能 | 常态产能、峰值产能和扩产能力 |
| 配合 | 沟通、变更响应、数据透明和售后处理 |
| 风险 | 单一供应、财务状况、知识产权和合规风险 |

供应商管理应形成准入、分级、绩效、整改和退出机制。

## 5. 采购与生产管理

主要工作包括：

- 采购计划和采购订单
- 价格谈判和成本拆解
- 物料与包装确认
- 生产排期和进度跟踪
- 来料、过程和出货检验
- 变更管理
- 异常处理和索赔
- 付款节点管理
- 交付绩效复盘

关键指标：采购成本下降率、准时交付率、合格率、返工率、交期偏差和供应商集中度。

## 6. 物流与仓储

物流方案需要综合商品体积重量、货值、时效、旺季、关税、平台规则和现金流。

主要环节：

```text
工厂出货 → 国内集货 → 头程运输 → 清关 → 海外仓/平台仓 → 尾程配送 → 退货逆向物流
```

主要管理对象：

- 海运、空运、铁路和快递方案
- FBA、FBT 和第三方海外仓
- 入仓预约和上架时效
- 物流轨迹和异常
- 仓租、操作费和尾程费用
- 退货、翻新、销毁和调拨

## 7. 库存经营原则

库存经营目标是：

**以最低合理库存支撑最大化销售，同时控制断货风险和现金占用。**

高库存不等于安全，可能意味着预测失真、补货规则粗糙或商品结构失衡。

## 8. 需求预测与补货

预测应考虑：

- 历史销量与趋势
- 季节性和节庆
- 广告与达人计划
- 价格和促销变化
- 新品爬坡和老品衰退
- 退货率
- 当前库存和在途库存
- 生产、运输和入仓 Lead Time
- 供应和物流波动

基础补货逻辑：

```text
建议补货量
= 预测需求
+ 安全库存
- 可售库存
- 有效在途库存
```

实际模型需明确预测周期、服务水平、最小起订量、整箱约束和资金上限。

## 9. 库存分类与处置

### ABC 分类

- A 类：高销售或高价值商品，重点保障供应和预测准确度。
- B 类：稳定经营商品，按标准规则补货。
- C 类：长尾或低贡献商品，控制库存和维护成本。

### 呆滞库存

处置方式包括：

- 优惠和清仓
- 套装或赠品
- 跨店、跨站点和跨仓调拨
- 渠道分销
- 翻新或重新包装
- 供应商退换
- 销毁或报废

处置决策应比较继续持有成本、降价损失和现金回收价值。

## 10. 关键指标

| 指标 | 说明 |
|---|---|
| 库存周转率 | 一定周期销售成本与平均库存的关系 |
| DOH | 当前库存可支持的销售天数 |
| OOS | 断货状态或断货比例 |
| Sell Through | 一定周期内售出数量占可售数量比例 |
| 预测准确率 | 预测与实际需求的偏差 |
| 呆滞库存率 | 超过目标库龄的库存占比 |
| 库存资金占用 | 库存对应的采购、物流和仓储资金 |
| 准时交付率 | 供应商按计划交付的比例 |
| 入仓时效 | 到港/到仓至可售的时间 |

## 11. 系统能力

典型系统包括：

- PLM：产品需求、打样、BOM、包装和生命周期。
- SRM：供应商准入、报价、绩效和协同。
- SCM/ERP：采购、生产、成本和库存计划。
- WMS：仓库库存、库位、入出库和盘点。
- TMS：运输计划、轨迹、费用和异常。
- OMS：订单、渠道库存和履约路由。

## 12. AI 应用

- 供应商匹配和评分。
- 报价与成本结构对比。
- 销量、补货和断货预测。
- 安全库存动态计算。
- 交期、质量和物流异常预警。
- 跨仓调拨与物流方案推荐。
- 呆滞库存识别和处置建议。
- 自动生成采购计划、补货计划和供应链周报。

涉及采购、付款、停产和大额补货的 AI 建议必须经过人工审批，并保留决策依据和版本。
