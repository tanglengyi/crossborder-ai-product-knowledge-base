# 跨境电商经营与 AI 产品知识库

这不是一份单纯的电商运营手册，而是一套从业务经营到平台产品设计的完整知识体系。

## 核心问题

知识库围绕六个问题展开：

1. 应该进入哪个市场、平台和品类？
2. 应该经营哪些商品，如何规划 SKU？
3. 如何以合理成本完成产品开发、采购、物流和库存周转？
4. 如何通过内容、达人、广告和店铺提升流量与转化？
5. 如何通过数据、财务和组织机制持续改善利润？
6. 如何把上述经营能力抽象为系统能力和 AI 智能体？

## 统一分析框架

每个业务主题原则上都从以下九个维度展开：

| 维度 | 要回答的问题 |
|---|---|
| 定义 | 这个主题是什么 |
| 目标 | 为什么要做 |
| 对象 | 管理什么业务对象 |
| 流程 | 从输入到输出如何运行 |
| 角色 | 谁负责、谁协同 |
| 指标 | 如何判断做得好不好 |
| 系统 | 需要什么平台与数据能力 |
| AI | 哪些环节可以智能化 |
| 案例 | 如何在真实业务中应用 |

## 知识层次

- **战略层**：市场、品类、品牌、财务与资源投入方向。
- **经营层**：商品、流量、库存、客户和利润经营。
- **执行层**：采购、内容、广告、物流、活动和客服动作。
- **支撑层**：数据、财务、系统、项目管理与组织协同。
- **智能层**：大模型、知识库、工作流、Agent 和预测模型。

## 推荐使用方式

- 学习业务：按首页推荐路线顺序阅读。
- 准备面试：重点学习 GM 经营系统、指标体系和业务闭环。
- 做产品方案：从业务对象、角色、流程、指标和系统能力五个维度拆解。
- 沉淀案例：使用案例模板记录背景、决策、结果和复盘。
- 建设 AI 产品：先识别业务决策，再设计数据、工具和智能体能力。
