# AI Business Operating System Knowledge Base（V3.1）

这是一套面向产业研究、全球商业、跨境增长、产品经营和 AI 产品设计的经营知识库。

> 产业/国家 → 客户 → 问题 → 价值 → 产品/解决方案 → 商业模式 → 定价 → GTM → 销售/交易 → 交付 → 客户成功 → P&L/现金流 → AI 化 → 复盘复制

## V3.1 核心升级

V3.1 补齐原知识库最明显的商业中段：

```text
客户是谁
→ 为什么买
→ 如何创造和量化价值
→ 如何收费与包装
→ 如何进入市场
→ 如何推进 Pipeline / POC
→ 如何报价、谈判、签约
→ 如何验收、回款
→ 如何续费、增购
```

并把分散知识收敛成六张总地图：**产业地图 × 地区地图 × 产品地图 × 增长地图 × 生态链地图 × AI Business OS 地图**。

## 推荐阅读路径

- 完整商业经营：`01 市场 → 10 商业引擎 → 02 产品供应链 → 03 增长 → 04 经营财务 → 05 AI BOS`
- 产业全球化：`11 战略地图 → 06 城市产业现场 → 01 市场机会 → 10 商业引擎`
- AI 产品：先研究客户、流程、交易和经营指标，再进入 `05-ai-business-os` 设计 Data、Knowledge、Workflow、Agent 和 Copilot。
