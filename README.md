# 跨境电商经营与 AI 产品知识库

本仓库用于系统沉淀跨境电商 GM 经营方法、TikTok 跨境业务流程、商品与供应链管理、增长营销、数据财务分析，以及 AI 电商经营平台的产品架构。

## 知识库目标

- 把零散经验拆成可检索、可复用、可持续扩展的知识单元。
- 同时服务于电商经营学习、岗位能力建设、业务方案设计和 AI 产品规划。
- 建立“战略—经营—执行—数据—系统—AI”的完整闭环。
- 所有知识文件直接平铺在仓库根目录，并通过两位序号保持稳定顺序。

## 编号规则

| 序号范围 | 内容 |
|---|---|
| `00–02` | 首页、知识地图和术语 |

| `18–89` | 后续新增专题、流程和案例 |
