# 版本更新日志（Release Notes）

## V3.1（2026-08-01）——TikTok AI 运营知识沉淀与来源治理

### 新增

- 新增《TikTok 数据驱动的市场判断与选品》，沉淀国家—类目—商品逐层下钻，以及动销率、Top10 集中度、新品占比、价格带和成交载体等判断指标。
- 新增《TikTok 达人运营体系》，覆盖达人发现、筛选、批量建联、动态人群包、履约跟进、风险管理和漏斗指标。
- 新增《TikTok AI 内容生产体系》，覆盖脚本拆解、仿写、本地化、AI 生成、视频复刻、AI+实拍、一键发布和内容单位经济模型。
- 新增《TikTok AI 运营闭环与 Agent 化》，将市场、达人、内容、评论分析、API、Skill 和 Agent 纳入 AI Business OS。
- 新增 Kalodata TikTok AI 运营案例研究，区分可迁移方法、产品能力、商业化策略和待验证主张。
- 建立首个知识来源档案 `S001`，记录来源贡献、可信度边界、未沉淀内容和后续验证方向。
- 新增《知识来源映射》，建立 Source ID、知识流向和知识演化记录规范。

### 重构与优化

- 将同一会议中的内容拆分进入市场策略、增长渠道、AI Business OS 和案例模块，而不是仅保留为孤立会议纪要。
- 将 Kalodata、Boost、Clip 和 AI 助手等具体产品降级为案例，把数据选品、达人生命周期、AI 内容管线和经营闭环提升为长期知识。
- 明确产品方主张、会议事实、知识抽象和后续验证之间的边界。

### 来源

- `S001`：Kalodata《AI 如何重新定义 TikTok 运营（实操演示）》会议纪要。

### V3.2 计划

- 将 S001 中的选品指标应用到真实 TikTok 类目，形成项目验证记录。
- 建立达人 CRM 状态机和自动跟进规则模板。
- 增加 AI 内容生成、AI+实拍与纯实拍的成本—转化对比模板。
- 逐步为既有核心文档补充 Source ID 与知识演化记录。

## V3.0（2026-07-29）——目录重构与 BOS 融合版

### 新增

- 建立十个一级主题文件夹，并为每个文件夹增加 README 说明。
- 新增《职业战略与行业起点》，明确产品经理向解决方案、商业化和经营岗位迁移的路径。
- 新增 V3.0 MkDocs 分层导航。

### 重构

- 将原来根目录平铺的知识文档全部迁移到对应主题目录。
- 统一知识主链路：行业与战略 → 客户与市场 → 产品与供应链 → 商业模式与交易 → 增长与渠道 → 经营与财务 → AI Business OS → 职业与创业实践。
- 将 BOS 从附加模块升级为整个知识库的顶层经营框架。

### 修复

- 解决根目录文件过多、序号重复和阅读入口混乱的问题。
- 统一 MkDocs 导航与 GitHub 文件结构。
- 将“工具资料”“案例项目”“模板规范”从业务方法论中分离。

### V3.1 计划

- 补齐客户研究、国家市场研究、商业模式、定价与单位经济模型。
- 建立智能装备、工业自动化、医疗设备三个行业地图。
- 增加国家市场模板、行业研究模板和决策 Memo 模板。
- 逐步修正文档内部的旧相对链接。
