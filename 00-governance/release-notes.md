# 版本更新日志（Release Notes）

## V3.1（2026-08-07）——Commercial Engine 与战略总地图补齐版

### 新增：商业引擎

新增 `10-commercial-engine`，补齐 BOS 原本最薄弱的商业中段：

- 客户研究：ICP、Persona、JTBD、VoC、DMU、Buying Journey；
- 商业模式与单位经济：SaaS、硬件、项目、平台、服务等收入结构及 CAC/LTV、毛利、贡献利润、现金流；
- 定价：Value Pricing、Cost-plus、竞争定价、Pricing Metric、版本包装、折扣与 Price Waterfall；
- 交易：Proposal、Deal Design、合同、付款、验收、Change Request、应收与 Deal Desk；
- B2B 销售：Lead→MQL→SQL→Opportunity→Win、Pipeline、Forecast、Account Planning；
- 售前与 POC：Discovery、Solution、Demo、POC/Pilot、RFI/RFP/RFQ、招投标、ROI/TCO；
- GTM 与渠道：直销、经销、代理、SI、ISV、OEM/ODM、伙伴经济和渠道冲突；
- 客户成功：Onboarding、Adoption、Health Score、Renewal、Expansion、Churn Review。

### 新增：战略总地图

新增 `11-strategy-maps`，把分散知识收敛成统一导航：

- 全球国家市场地图：美国、欧洲、日本、东南亚、中东、拉美及标准 Market Entry Memo；
- 产业与行业地图：消费品、消费硬件、机器人/智能装备、工业制造、数字产品/AI、内容/IP；
- 产品系统地图：Physical Product + Digital Product + Service Product；
- 全球商品与服务生态链：供应、制造、产品、商业、增长、渠道、履约、金融合规与数字基础设施；
- 六张总地图：产业 × 地区 × 产品 × 增长 × 生态链 × AI Business OS。

### 强化：产业与地区研究

- 新增广州科技出海产业地图与全国产业巡航方法论；
- 把广州的内容游戏、跨境电商、汽车机器人、智能硬件和珠三角供应链连接起来；
- 将城市观察升级为“产业节点 → 客户问题 → 产品机会 → 商业验证 → 知识资产”的长期研究机制。

### 重构

BOS 主链升级为：

> **产业/国家 → 客户 → 问题 → 价值 → 产品/解决方案 → 商业模式 → 定价 → GTM → 销售/交易 → 交付 → 客户成功 → P&L/现金流 → AI 化 → 复盘复制**

### 下一阶段

V3.2 不再优先继续堆框架，重点把关键模块从 L1/L2 推进到 L3：

- 真实客户访谈与 DMU 案例；
- 真实报价、折扣、合同、验收和回款案例；
- 美国、日本、东南亚等国家市场实证；
- 机器人、AI 硬件、工业自动化等行业深度档案；
- B2B Pipeline、POC 和渠道真实项目复盘；
- 六张总地图对应的标准模板和案例。

## V3.0（2026-07-29）——目录重构与 BOS 融合版

### 新增

- 建立十个一级主题文件夹，并为每个文件夹增加 README 说明。
- 新增《职业战略与行业起点》，明确产品经理向解决方案、商业化和经营岗位迁移的路径。
- 新增 V3.0 MkDocs 分层导航。

- 将原来根目录平铺的知识文档全部迁移到对应主题目录。
- 统一知识主链路：行业与战略 → 客户与市场 → 产品与供应链 → 商业模式与交易 → 增长与渠道 → 经营与财务 → AI Business OS → 职业与创业实践。
- 将 BOS 从附加模块升级为整个知识库的顶层经营框架。

### 修复

- 解决根目录文件过多、序号重复和阅读入口混乱的问题。
- 统一 MkDocs 导航与 GitHub 文件结构。
- 将“工具资料”“案例项目”“模板规范”从业务方法论中分离。
