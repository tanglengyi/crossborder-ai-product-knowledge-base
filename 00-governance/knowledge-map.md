## 5. 五类核心经营对象

### 产品

管理产品系统、SKU、版本、生命周期、价格、成本、毛利和组合关系。

### 客户

管理 ICP、联系人、DMU、购买旅程、采用、留存、续费和 LTV。

### 增长与销售

管理内容、达人、广告、渠道、Lead、Pipeline、Win Rate、CAC 和销售周期。

### 交付与供应

管理供应商、采购、库存、项目、履约、验收、售后和 SLA。

### 资金

管理预算、收入、毛利、贡献利润、应收、库存资金、现金流和资本效率。

## 6. 核心知识实体

| 实体 | 典型关系 |
|---|---|
| Industry | 包含价值链、公司、客户、利润池和监管 |
| Country/City | 连接产业、客户、政策、渠道和供应链 |
| Account | 包含联系人、DMU、商机、合同和客户成功 |
| Customer/Persona | 产生 JTBD、需求、异议和价值判断 |
| Product | 连接客户价值、成本、版本、供应链和渠道 |
| Supplier | 提供报价、MOQ、交期、质量、认证和产能 |
| Opportunity | 连接客户问题、金额、阶段、竞争和 Close Date |
| Quote/Deal | 连接价格、折扣、付款、范围和风险 |
| Contract | 连接交付、验收、回款、责任和续费 |
| Channel/Partner | 连接获客、销售、服务、利润分配和客户覆盖 |
| Order/Project | 连接收入、成本、交付和客户结果 |
| Metric | 描述业务对象状态与经营结果 |
| Decision | 基于目标、数据、规则、约束产生经营动作 |
| Knowledge | 沉淀事实、规则、SOP、案例和决策证据 |

## 7. 内容成熟度

- **L0 占位**：标题或零散提纲；
- **L1 框架**：概念、结构和关键问题完整；
- **L2 可执行**：流程、指标、模板和检查表齐全；
- **L3 已验证**：真实客户、交易、数据和复盘验证。

V3.1 的重点变化是：原来很多 L0/L1 的“客户、定价、交易、国家市场、行业地图”已经提升到 L1/L2；下一阶段重点是增加真实案例把关键知识推进到 L3。

## 8. 扩展原则

1. 一个文件解决一个主要问题。
2. 方法论、案例、模板和来源分开管理。
3. 同一概念只保留一个权威定义，其他文件通过链接引用。
4. 新知识优先放进六张总地图之一，避免孤立文档。
5. 行业研究必须连接客户、利润池、产品、商业模式和城市/国家节点。
6. AI 研究必须连接真实业务对象、流程、数据、权限和结果指标。
7. 案例必须区分事实、判断、假设和建议。
8. 重要指标写清公式、口径、数据源、频率和责任人。
