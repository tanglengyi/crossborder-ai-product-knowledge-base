# 商业模式与单位经济模型

## 1. 核心问题

商业模式回答：**企业如何创造价值、交付价值并获得价值。** 不只问“卖什么”，还要问谁付钱、按什么单位收费、多久收一次、成本如何随规模变化、现金什么时候回来。

## 2. 常见收入模式

| 模式 | 适用场景 | 主要风险 |
|---|---|---|
| 一次性商品销售 | 消费品、硬件、设备 | 复购弱、价格竞争 |
| 订阅 | SaaS、会员、AI服务 | 留存、续费、服务成本 |
| 用量计费 | API、云服务、物流、AI推理 | 成本波动、预测难 |
| 项目制 | 咨询、集成、定制系统 | 人效、范围失控、不可复制 |
| License | 软件授权、IP授权 | 续费与盗版/合规 |
| 佣金/抽成 | 平台、撮合、交易服务 | 供需两端与平台依赖 |
| 广告 | 内容、媒体、流量平台 | 流量质量与周期性 |
| 服务费 | 实施、售后、认证、培训 | 人力交付占比高 |
| 金融/支付费 | 支付、供应链金融 | 风控、监管、资本要求 |

## 3. 组合商业模式

很多高质量业务不是单一收费方式。

### 智能硬件

```text
设备收入
+ 配件/耗材
+ 延保/售后
+ App/云订阅
+ AI增值功能
+ 企业服务
```

### 企业 SaaS

```text
订阅
+ 实施
+ API / 用量
+ 高级模块
+ 培训/顾问
+ 生态分成
```

### 平台

```text
交易佣金
+ 广告
+ 会员
+ 软件工具
+ 金融/物流服务
```

## 4. Business Model Canvas 的经营化版本

建议研究任何业务时回答：

1. 客户是谁？
2. 客户购买什么结果？
3. 产品如何交付结果？
4. 收费单位是什么？
5. 价格如何形成？
6. 获客渠道是什么？
7. 关键资源和能力是什么？
8. 哪些活动最影响成本？
9. 哪些伙伴不可替代？
10. 毛利、贡献利润和现金流如何？
11. 哪些环节能规模化？
12. 壁垒来自数据、品牌、网络、供应链、技术还是切换成本？

## 5. 单位经济模型

### 通用结构

```text
Revenue
- Variable Cost
= Gross Profit
- Acquisition / Fulfillment / Service Variable Cost
= Contribution Profit
```

必须区分：

- Gross Margin：产品本身的毛利；
- Contribution Margin：扣掉随业务增长变化的获客、履约、佣金、服务等成本后的贡献；
- Operating Profit：再扣固定团队、研发、管理等费用后的经营利润。

## 6. SaaS 核心指标

- MRR / ARR：月度/年度经常性收入；
- Logo Retention：客户数量留存；
- GRR：不含扩张的收入留存；
- NRR：包含增购、降配和流失后的净收入留存；
- CAC：获得一个客户的销售与营销成本；
- LTV：客户生命周期价值；
- CAC Payback：获客成本回收周期；
- Gross Margin：订阅收入扣除直接交付成本后的毛利。

LTV/CAC 只是简化判断，不能替代 cohort、现金回收和销售周期分析。

## 7. 电商与品牌单位经济

单订单/单 SKU 应至少拆：

```text
成交收入
- 折扣/退款
- 商品成本
- 平台佣金
- 支付费
- 头程/仓储/尾程
- 广告/达人佣金
- 售后与退货损失
= Contribution Profit
```

不能只用 ROAS 判断赚钱，因为 ROAS 不包含完整成本。

## 8. 硬件与设备经济模型

关注：

- BOM 与制造成本；
- 模具/NRE 摊销；
- 质检、认证和包装；
- 渠道毛利；
- 物流与库存资金；
- 保修准备和售后成本；
- 退货/故障率；
- 软件云成本；
- 服务收入与耗材复购。

硬件低毛利可以被软件/耗材补贴，但必须确认附加收入真实存在，而不是“以后可能有”。

## 9. 项目制与解决方案经济模型

项目收入需要同时看：

- 合同金额；
- 软硬件采购；
- 实施人天；
- 差旅；
- 第三方费用；
- 变更；
- 验收延迟；
- 应收账款；
- 售后维保。

核心风险是“看起来高毛利，实际被定制、延期和回款吞掉”。

## 10. 现金转换周期

利润和现金不是一回事。

```text
采购付款
→ 生产/库存
→ 销售
→ 应收
→ 收款
```

跨境和硬件尤其要管理：库存天数、应收天数、应付天数、广告预付和平台回款周期。

## 11. 商业模式评估框架

从以下维度评分：

- 客户价值强度；
- 收入可预测性；
- 毛利率；
- 贡献利润；
- CAC 与销售周期；
- 复购/续费；
- 现金占用；
- 交付复杂度；
- 可复制性；
- 平台/大客户依赖；
- 合规风险；
- 防御性壁垒。

## 12. AI 商业模式

AI 产品必须额外考虑：模型调用、推理、向量库、数据处理、人工审核、第三方工具调用等变动成本。定价不能只参考传统 SaaS，需要明确 Token/任务/席位/结果的收费单位与成本护栏。
