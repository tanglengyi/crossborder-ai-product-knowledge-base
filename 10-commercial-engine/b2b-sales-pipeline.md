# B2B 销售与 Pipeline 经营

## 1. 核心目标

B2B 销售不是“多跟客户聊”，而是把有限销售资源配置给高质量机会，并通过可验证阶段推进成交。

## 2. 标准漏斗

```text
Lead
→ MQL
→ SQL
→ Opportunity
→ Discovery
→ Solution / Demo
→ POC / Evaluation
→ Proposal
→ Negotiation
→ Commit
→ Closed Won / Lost
→ Implementation
→ Renewal / Expansion
```

不同公司可以调整命名，但每个阶段必须有明确进入和退出条件。

## 3. Lead 与 Qualification

Lead 来源包括：

- 官网询盘；
- 内容/SEO；
- 广告；
- 展会；
- SDR 外呼/邮件；
- 渠道伙伴；
- 客户转介绍；
- 产品试用；
- 生态合作。

Qualification 至少判断：Fit、Pain、Priority、Authority、Process、Timing。

## 4. MQL / SQL 不应只按行为分数

MQL 表示营销判断“值得销售关注”，SQL 表示销售确认“存在真实机会”。

需要同时看：

- ICP Fit；
- 行为意图；
- 问题强度；
- 预算/资源；
- 决策角色；
- 项目时间。

下载三份白皮书不等于真实商机。

## 5. Opportunity 阶段门

建议设置：

| 阶段 | 必须证据 |
|---|---|
| Discovery | 明确现状、问题、影响和目标 |
| Qualified | 有 Champion、决策流程、时间窗口 |
| Solution Fit | 方案与关键需求匹配 |
| Evaluation | POC/测试标准和责任人明确 |
| Proposal | 商务范围、价格和采购路径明确 |
| Negotiation | 关键条款和竞争态势清晰 |
| Commit | 预算、审批、签署与采购时间高度确定 |

## 6. Pipeline Metrics

必须监控：

- Pipeline Value；
- Pipeline Coverage；
- Win Rate；
- Average Deal Size；
- Sales Cycle；
- Stage Conversion；
- Stage Aging；
- Forecast Accuracy；
- New Pipeline Created；
- Lost Reason；
- Rep Productivity。

## 7. Pipeline Coverage

例如季度目标为 1000 万，历史从合格 Pipeline 到成交率为 25%，理论上需要约 4000 万有效 Pipeline。

但 Coverage 不能只看金额，还要看：阶段质量、客户集中度、预计签约时间和 Deal 风险。

## 8. Forecast

建议分层：

- Pipeline：仍有较大不确定性；
- Best Case：满足多数条件但仍有风险；
- Commit：销售负责人有高信心在周期内成交；
- Closed：已成交。

预测必须基于客户证据而不是销售感觉。

## 9. Multi-threading

复杂交易不能只依赖一个联系人。需要建立：

```text
Champion
+ Economic Buyer
+ User
+ Technical Buyer
+ Procurement
+ Finance
+ Legal/Security
```

如果只认识一个使用者，交易风险很高。

## 10. Account Planning

大客户经营应记录：

- 组织结构；
- 战略目标；
- 现有产品部署；
- 白空间机会；
- 关键关系；
- 竞争格局；
- 合同与续费；
- 风险；
- 下一年度 Expansion Plan。

## 11. Territory 与销售资源

可按地区、行业、客户规模、产品线或命名大客户划分 Territory。

设计原则：

- 市场潜力相对公平；
- 避免客户归属冲突；
- 与产品/渠道战略一致；
- 让销售有足够密度形成行业认知。

## 12. 销售节奏

### 日常

下一步行动、关键客户阻塞。

### 每周

Pipeline Review：重点看阶段变化、风险和 Next Step，不是逐条念 CRM。

### 每月

Forecast、Win/Loss、渠道来源、销售周期、客单和行业表现。

### 每季度

Territory、ICP、配额、渠道与资源配置调整。

## 13. CRM 数据规范

核心对象：Account、Contact、Lead、Opportunity、Activity、Quote、Contract、Product、Renewal。

每个 Opportunity 至少维护：

- 金额；
- 产品；
- 阶段；
- Close Date；
- Champion；
- Economic Buyer；
- Competition；
- Next Step；
- Risk；
- Lost Reason。

## 14. 销售与产品协同

销售不应把所有客户要求直接变成 Roadmap。产品团队需要区分：

- 单一客户定制；
- 多客户重复需求；
- 战略行业能力；
- 合规刚需；
- 可收费扩展；
- 不应承诺的范围。

## 15. AI 销售应用

- Lead/Account 研究；
- 通话摘要与行动项；
- Discovery 信息抽取；
- 商机风险识别；
- Next Best Action；
- Proposal 草拟；
- RFP 解析；
- Forecast 辅助；
- Win/Loss 聚类。

AI 不能替销售虚构客户承诺，关键阶段必须基于 CRM、邮件、会议和合同证据。
