# GTM、渠道与伙伴体系

## 1. GTM 的定义

Go-To-Market 不是单纯营销计划，而是回答：**选择哪个市场、卖给谁、通过什么渠道、用什么价值主张、以什么价格和销售动作把产品推向市场。**

## 2. GTM 基础结构

```text
Market
→ Segment
→ ICP
→ Positioning
→ Value Proposition
→ Offer / Package
→ Pricing
→ Channel
→ Sales Motion
→ Launch
→ Measurement
```

## 3. 市场进入方式

- Product-led：试用、自助购买、自然扩张；
- Sales-led：销售驱动复杂交易；
- Marketing-led：内容、活动、广告生成需求；
- Partner-led：依赖渠道、经销、SI、生态伙伴；
- Marketplace-led：借助 Amazon、TikTok、云市场等平台；
- Hybrid：多数成熟公司采用混合模式。

## 4. Sales Motion

### SMB

- 低客单；
- 短销售周期；
- 高自动化；
- Inside Sales / Self-service。

### Mid-market

- 需要方案与 Demo；
- 多角色决策；
- 标准产品 + 部分服务。

### Enterprise

- 长周期；
- 多部门；
- 安全、采购、法务复杂；
- POC、RFP、定制、集成和高层关系重要。

## 5. 渠道类型

| 类型 | 核心价值 |
|---|---|
| Distributor 分销商 | 库存、覆盖、下级渠道 |
| Reseller 经销商 | 获客、报价、销售、交付 |
| Agent 代理 | 商务撮合或区域销售 |
| SI 系统集成商 | 集成、项目交付、行业客户 |
| ISV | 软件能力互补 |
| MSP | 托管和持续服务 |
| Referral | 线索推荐 |
| Affiliate | 按转化佣金 |
| OEM/ODM | 产品制造或白牌 |
| Marketplace | 平台流量、交易与生态 |

## 6. Direct vs Channel

选择维度：

- 客户集中度；
- 客单价；
- 销售复杂度；
- 本地服务要求；
- 地理覆盖；
- 品牌控制；
- 资金和库存；
- 渠道成熟度；
- 毛利空间。

渠道不是“免费的销售团队”，需要利润、培训、线索、产品支持和规则治理。

## 7. Partner Economics

需要明确：

- Discount / Margin；
- Rebate；
- MDF 市场基金；
- Referral Fee；
- Deal Registration；
- 年度目标；
- 返利阶梯；
- 库存责任；
- 售后责任；
- 回款责任。

渠道政策必须防止跨区、乱价、抢单和虚假报备。

## 8. Partner Lifecycle

```text
招募
→ 资格评估
→ 签约
→ Onboarding
→ 培训/认证
→ 联合营销
→ Deal Registration
→ 销售/交付
→ 绩效评估
→ 分级激励
→ 整改/退出
```

## 9. Channel Conflict

常见冲突：

- 厂商直销与代理抢客户；
- 多家渠道报备同一商机；
- 线上价格破坏线下；
- 跨区域销售；
- 总代理与二级渠道利益冲突。

需要 Deal Registration、客户归属、价格保护和升级机制。

## 10. 跨境 GTM

进入一个国家至少判断：

- 本地需求；
- ICP；
- 合规认证；
- 语言/内容本地化；
- 价格与支付；
- 平台/经销/直销渠道；
- 本地仓与物流；
- 售后；
- 税务；
- 本地团队/伙伴。

不要把“上线当地 Amazon/TikTok 店铺”当成完整市场进入。

## 11. Launch

上市前检查：

- 定位和信息；
- SKU / Package；
- Price；
- 销售材料；
- Demo；
- 客服知识；
- 库存/交付；
- 渠道培训；
- 数据埋点；
- Campaign；
- 风险预案。

## 12. GTM Metrics

- Pipeline；
- CAC；
- Win Rate；
- Sales Cycle；
- Revenue by Channel；
- Partner-sourced Revenue；
- Partner-influenced Revenue；
- Activation；
- Retention；
- Market Share；
- Contribution Margin。

## 13. AI 应用

AI 可辅助市场细分、Account Research、伙伴筛选、渠道培训、销售材料本地化、线索路由和伙伴绩效诊断，但渠道关系、价格冲突和战略伙伴决策仍需业务负责人判断。
