# 10｜商业引擎 Commercial Engine

本模块补齐 BOS 中最关键的“商业中段”：**客户 → 价值 → 商业模式 → 定价 → GTM → 销售 → 交易 → 交付 → 客户成功**。

它解决的不是“怎么把功能做出来”，而是：**谁愿意付钱、为什么付钱、付多少钱、由谁决策、如何签约、如何回款，以及如何形成可复制收入。**

## 主链路

```text
市场与行业
→ ICP / 客户问题
→ 价值主张
→ 产品 / 解决方案
→ 商业模式
→ 包装与定价
→ GTM
→ Pipeline
→ POC / Proposal
→ 谈判与合同
→ 交付与验收
→ 回款
→ 客户成功
→ 续费 / 增购 / 转介绍
```

## 统一原则

1. **产品价值不等于功能数量**：必须对应客户可感知的收入增长、成本下降、风险降低、效率提升或体验改善。
2. **用户不等于买单者**：B2B 必须识别使用者、影响者、预算拥有者、采购、法务、IT、安全与最终决策者。
3. **收入不等于利润**：任何商业模式必须同时看毛利、贡献利润、现金转换周期和资本占用。
4. **标价不等于成交价**：必须管理折扣、返点、渠道利润、服务、账期和风险溢价形成的 Price Waterfall。
5. **签约不等于成功**：交付、验收、回款、采用、续费和扩张才构成完整交易闭环。
