# 增长营销与销售运营

## 1. 模块目标

增长营销负责获得可持续、可盈利的流量；销售运营负责把流量转化为订单和利润。两者不能割裂：低转化会放大获客成本，低质量流量也会降低 Listing 和店铺效率。

## 2. 增长飞轮

```text
用户洞察
→ 商品卖点
→ 内容与素材
→ 达人/广告/搜索分发
→ 访问与互动
→ Listing 转化
→ 订单与评价
→ 数据反馈
→ 新素材和新策略
```

## 3. 内容运营

内容不是产品参数的重复，而是把商品放入真实场景，表达“谁在什么情况下，为什么需要它，使用后发生什么变化”。

主要内容形式：

- 短视频
- 直播
- 达人素材
- UGC
- 测评和对比
- 教程和 FAQ
- 品牌故事
- AI 生成图片、脚本和视频

内容拆解维度：

- 前 3 秒钩子
- 用户痛点
- 使用场景
- 演示过程
- 结果对比
- 可信证据
- CTA
- 镜头、字幕、音乐和节奏
- 评论区反馈

## 4. 达人合作

### 合作对象

- 中小达人
- 垂直专家
- 头部达人
- MCN
- Affiliate 联盟成员

### 合作模式

- 寄样
- 固定报价
- CPS 佣金
- CPA
- 保底加佣金
- 长期品牌合作

### 达人运营流程

```text
达人搜索 → 筛选评分 → 建联 → 寄样 → 内容沟通 → 发布 → 数据追踪 → 结算 → 分层复用
```

达人评估应关注受众匹配、历史带货、互动质量、内容风格、报价、履约稳定性和素材复用权，而不只看粉丝数。

## 5. 广告投放

主要平台：TikTok Ads、Amazon PPC、Meta、Google 和 Pinterest。

标准投放流程：

```text
目标定义
→ 人群与渠道选择
→ 素材准备
→ 小预算测试
→ 识别有效组合
→ 放量
→ 监控边际回报
→ 淘汰或迭代
```

优化对象包括：

- 素材
- 人群
- 出价
- 预算
- 落地页
- 商品
- 价格与促销
- 归因窗口

广告投放应设定最低可接受 ROAS 或最高 CAC，避免用亏损投放掩盖商品、价格或转化问题。

## 6. 搜索与自然流量

- 平台搜索词和关键词布局
- 标题、属性和类目准确性
- SEO 内容
- 用户评价和问答
- 品牌词增长
- 自然推荐流量
- EDM、社群和私域回流

长期目标是提高自然流量和品牌流量占比，降低对付费广告的单一依赖。

## 7. Listing 与店铺转化

### Listing 要素

- 标题与关键词
- 主图和场景图
- 视频
- 卖点和详情页
- A+ 页面
- 参数与规格
- FAQ
- 用户评价
- 配送和售后承诺

### 促销与价格

- 优惠券
- 秒杀
- 限时折扣
- 满减
- 套装
- 赠品
- 会员价
- 分层定价

价格策略需要同时考虑定位、竞争、成本、库存、促销和客户感知，不能只以竞品最低价为基准。

## 8. 核心指标

### 流量指标

- Impression
- Reach
- 视频完播率
- 互动率
- CTR
- CPC

### 转化指标

- 商品页访问量
- 加购率
- 结账率
- CVR
- 客单价
- 连带率
- 支付成功率

### 投放指标

- 广告消耗
- CPA
- CAC
- ROAS
- ACOS
- 边际 ROAS
- LTV/CAC

### 达人指标

- 建联回复率
- 寄样发布率
- 单达人 GMV
- 佣金率
- 内容复用率
- 达人留存率

## 9. 归因与实验

经营团队应明确归因窗口和平台差异，避免把同一订单重复归因给多个渠道。

实验建议：

- 一次主要验证一个变量。
- 预先定义目标指标、护栏指标和停止条件。
- 保留素材、受众、商品、价格和时间信息。
- 区分短期广告效果与长期品牌效果。
- 对放量后的边际回报持续观察。

## 10. 系统能力

- 内容资产管理和标签
- 达人搜索、建联、CRM 和结算
- 跨平台广告数据整合
- 素材版本与实验管理
- Listing 和价格管理
- 活动日历与预算管理
- 营销归因
- 增长看板和异常预警

## 11. AI 应用

- 用户评论和爆款内容洞察。
- 脚本、图片、视频和多语言文案生成。
- 达人匹配、报价预测和自动建联。
- 素材评分、相似素材生成和疲劳预警。
- 广告预算、出价和人群建议。
- Listing 优化和搜索词推荐。
- 经营异常诊断与下一步动作建议。

AI 生成内容必须经过品牌、事实、版权、平台政策和本地文化检查。
