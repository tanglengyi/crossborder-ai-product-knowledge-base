# TikTok 达人运营体系

## 1. 达人不是名单，而是一条经营链路

达人运营的核心不是找到更多账号，而是持续提高“合适达人进入合作并产出有效内容”的概率。完整链路包括：

> 达人发现 → 精准筛选 → 建联 → 寄样 → 签收 → 催拍 → 内容发布 → 成交评估 → 分层复用

单纯批量发私信只能解决建联效率，无法替代后续寄样、履约、关系维护和复购管理。

## 2. 达人发现方式

### 2.1 按商品与类目发现

从目标商品、三级类目或相关关键词出发，寻找已经在相近价格带和消费人群中产生过成交的达人。

### 2.2 按竞品反向发现

从优质竞品店铺或爆款商品中导出合作达人，判断哪些达人已经验证过相近商品、内容结构和受众。这种方式可以降低从零筛选的成本，但不能机械复制，因为达人可能已被竞品绑定或受众已疲劳。

### 2.3 从外部数据补充

平台原生数据通常只展示总成交额或主类目，外部数据工具可以进一步细分至具体类目成交、语言、性别和国家等维度。使用外部工具时，需要同时评估数据更新时间、口径和准确度。

## 3. 达人筛选框架

| 维度 | 判断重点 |
|---|---|
| 类目相关性 | 是否长期发布相近类目，而非偶发带货 |
| 具体商品成交 | 是否在目标商品或相似商品上有真实成交 |
| 内容能力 | 镜头表达、脚本结构、卖点呈现是否适配商品 |
| 受众匹配 | 国家、语言、性别、年龄与购买人群是否一致 |
| 历史履约 | 是否按时签收、拍摄、发布，是否存在骗样风险 |
| 价格与佣金 | 报价、佣金和预期 GMV 是否可覆盖成本 |
| 可持续合作 | 是否具备复投、系列内容和长期合作空间 |

## 4. 批量建联的正确边界

批量建联适合替代重复劳动，但不能替代策略：

- 人群包应按类目、国家、语言、历史成交和合作阶段进行分层；
- 邀约文案需要针对商品卖点、样品政策和达人特点做差异化；
- 重点监控送达率、回复率、同意率、寄样率、发布率和成交率；
- BD 节省出的时间应投入到提升回复率、优化合作条件和维护优质达人。

## 5. 动态人群包与自动跟进

动态人群包的本质，是根据达人所处阶段自动纳入或移出对应任务，例如：

- 已邀约未回复：自动发送一次合理跟进；
- 已同意未寄样：提醒运营处理寄样；
- 已寄样未签收：同步物流状态；
- 已签收未拍摄：按约定节点催拍；
- 已发布未出单：分析内容与商品匹配问题；
- 已出单：进入复投与长期合作池。

自动化应服务于明确的阶段规则，避免无节制地群发消息损害达人关系。

## 6. 达人风险管理

针对骗样或低履约风险，可以组合使用：

- 历史带货和发布记录；
- 同类商品合作表现；
- 黑名单或共享风险记录；
- 小批量寄样与分层权益；
- 明确交付时间、内容要求和沟通记录；
- 将样品成本、发布率和成交率纳入达人单位经济模型。

## 7. 达人运营指标

建议至少跟踪：

> 候选人数 → 有效触达率 → 回复率 → 同意合作率 → 寄样率 → 签收率 → 发布率 → 出单率 → 单达人 GMV → 获客成本 → 复投率

只有把这些阶段数据连起来，才能判断问题出在筛选、邀约、履约、内容还是商品本身。
