# TikTok 数据驱动的市场判断与选品

## 1. 为什么不能只靠经验选品

TikTok 电商竞争从流量红利阶段进入精细化经营阶段后，选品的目标不再是追逐播放量，而是提高商品进入市场后的成交概率与投入产出比。经验仍有价值，但需要被市场规模、增长速度、竞争强度、价格带和成交载体等数据校验。

## 2. 漏斗式市场判断

建议按照“国家 → 一级类目 → 二级类目 → 三级类目 → 商品”的顺序逐层下钻：

1. 先选择目标国家，确认平台覆盖、消费能力、物流与合规条件。
2. 在一级类目观察市场规模、增长趋势与主要成交载体。
3. 在二级类目判断竞争结构、价格带和新品机会。
4. 在三级类目定位具体商品类型，验证供给与需求是否匹配。
5. 最后进入商品、店铺、达人和内容层进行交叉验证。

这一流程的价值，是先看市场天花板，再寻找可进入的细分机会，避免直接从单个爆款倒推整个市场。

## 3. 核心判断指标

| 指标 | 解决的问题 | 使用方式 |
|---|---|---|
| 市场规模与增长率 | 市场是否足够大、是否仍在增长 | 同时观察绝对规模和近期趋势，避免只看增长百分比 |
| 动销率 | 上架商品获得成交的难易程度 | 动销率高通常意味着需求更广，但仍需排除低价促销影响 |
| Top10 店铺成交占比 | 市场是否被头部垄断 | 占比过高时，新进入者需要更强供应链、品牌或渠道优势 |
| 新品成交占比 | 新商品是否仍有进入窗口 | 结合新品数量、上架时间和测款成本判断，而非单看占比 |
| 价格带分布 | 主流消费者愿意支付多少 | 结合成本、佣金、物流、退货和内容成本计算可行毛利 |
| 成交载体 | 短视频、直播或商品卡谁承担成交 | 决定团队应优先建设哪一种内容与渠道能力 |
| 平均售价 | 市场定位与用户层级 | 用于筛选可参考店铺和达人，避免跨价格带误判 |

## 4. 蓝海不是“低竞争”这么简单

可进入的细分市场通常需要同时满足：

- 需求规模不是过小；
- 增长趋势仍然健康；
- 头部集中度不过高；
- 新品仍能获得成交；
- 价格带覆盖完整成本；
- 团队能够匹配主要成交载体；
- 供应链、物流和内容能力至少有一项差异化优势。

因此，蓝海更接近“竞争结构与自身能力匹配”，而不是简单寻找卖家数量少的类目。

## 5. 从榜单发现商品后的二次验证

新品榜、爆品榜只能作为线索，不能直接作为采购结论。至少需要继续验证：

1. 近 7 天成交是否持续，而不是单日偶发增长；
2. 商品是否依赖单一达人或单条爆款视频；
3. 店铺历史、价格变化和促销力度是否异常；
4. 相关达人是否可复制，内容结构是否可复用；
5. 评论中真实购买动机、好评点和差评风险是什么；
6. 毛利能否覆盖达人佣金、样品、内容、物流和退货成本。

## 6. 与经营闭环的关系

数据选品不是独立动作，而是后续达人、内容和复盘的起点：

> 市场判断 → 商品筛选 → 竞品店铺拆解 → 达人验证 → 内容测款 → 成交复盘 → 重新调整市场和商品判断
