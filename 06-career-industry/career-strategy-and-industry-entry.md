# 职业战略与行业起点

## 1. 当前能力底盘

- 嵌入式软件与医疗机器人早期经验；
- 多年 ToB 软件产品、平台产品和项目协同经验；
- AI 产品、知识库、工作流与 Agent 理解；
- 当前补充智能硬件、全球市场和商业经营认知。

## 2. 职业迁移目标

> 产品交付 → 解决方案 / 售前 → 商业化经营 → 业务拓展 / 产品线经营

目标不是直接跳到“海外运营负责人”，而是逐步获得客户、方案、报价、交易和经营结果证据。

## 3. 长期行业主线

优先方向：**中国智能制造出海（Smart Equipment Globalization）**。

候选行业：

1. 智能装备与服务机器人；
2. 工业自动化、AI 视觉与智能检测；
3. 智能仓储、AGV 与物流自动化；
4. 医疗设备与医疗机器人；
5. 智慧农业设备；
6. 智能庭院与户外机器人。

## 4. 行业进入八问

1. 海外需求是否真实、持续？
2. 是否存在技术、认证、交付或服务门槛？
3. 客户是否不仅按最低价决策？
4. 是否能发挥软件、AI、产品和复杂系统理解能力？
5. 能否从单品扩展到解决方案？
6. 是否存在可进入的供应链与渠道路径？
7. 能否积累客户、案例、数据和品牌资产？
8. AI 是提升效率，还是会抹平差异化？

## 5. 无资源起步路径

> 行业研究 → 专业内容 → 海外受众 → 客户访谈 → 供应链网络 → 小项目验证 → 真实交易 → 品牌与解决方案

第一阶段不急于开公司、囤货或投广告，先形成四类证据：研究证据、市场证据、交付证据和经营证据。

## 6. 未来十二个月输出

- 完成三个候选行业地图；
- 访谈至少十位工厂、渠道或潜在客户；
- 形成一个英文专业内容账号；
- 完成一份市场进入 Memo 和一套解决方案样例；
- 尝试获得询盘、样品测试或小额试单。
