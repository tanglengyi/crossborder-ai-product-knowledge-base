# 中国商业认知地图

> 目标：把城市、产业与商业模式连接起来，形成一套可以长期更新、反复复用的商业判断框架。

## 一、为什么要建立商业认知地图

这次出行已经不只是旅游，而是在搭建自己的**中国商业认知地图**。

当前路线：

> **义乌 → 深圳 → 珠海 → 广州**

这四座城市分别代表四种不同的商业能力：

| 城市 | 关键词 | 核心学习目标 |
|---|---|---|
| 义乌 | 全球供应链、小商品、外贸 | 商品如何被组织、采购并卖向全球 |
| 深圳 | 科技、AI、硬件、跨境、创业 | 产品如何被设计、制造并形成增长 |
| 珠海 | 文旅、IP、体验消费 | 如何让消费者愿意投入时间并持续消费 |
| 广州 | 消费品牌、批发、直播、渠道 | 如何通过品牌、渠道与规模化交易形成优势 |

这四个部分拼在一起，已经覆盖了一家公司从商品、产品、体验到渠道与销售的大半条价值链。

## 二、第一阶段：看懂中国为什么能做出产品

这是当前正在完成的阶段。

### 义乌：供应链与全球贸易

重点观察：

- 小商品如何形成低成本、低门槛、高密度的供应网络；
- 商户如何完成报价、起订、交付、物流和外贸协同；
- 普通商品如何通过包装、内容、达人和渠道被重新定价；
- 跨境平台如何影响商品结构、利润和库存。

### 深圳：科技、硬件与出海

重点观察：

- AI、消费电子、智能硬件如何从样品进入量产；
- 产品、供应链、品牌和跨境渠道如何协同；
- 华强北、南山、前海和展会生态如何构成产业网络；
- AI 在真实商业中究竟创造收入、降低成本，还是只作为营销标签。

### 广州：消费、品牌与渠道

重点观察：

- 批发、服装、美妆、食品和餐饮如何形成产业集群；
- 直播、电商、线下批发和品牌运营如何协同；
- 传统商贸如何通过渠道效率和规模优势长期存在；
- 为什么广州更擅长把商品变成消费品牌。

### 珠海：文旅、IP与体验消费

重点观察：

- 大型文旅项目如何设计动线、停留时间和二次消费；
- 门票、住宿、餐饮、纪念品和演出如何组合；
- IP、场景和体验如何提高客单价；
- 家庭客群为什么愿意为完整体验持续付费。

## 三、第二阶段：深入中国制造腹地

推荐路线：

> **东莞 → 佛山 → 中山 → 顺德**

### 东莞：制造业、OEM与ODM

主题：**消费电子与智能制造**。

重点观察：

- 消费电子；
- AI 硬件；
- OEM 与 ODM；
- 自动化工厂；
- 模具、注塑、组装、测试和交付；
- 小团队如何借助成熟供应链快速出货。

东莞与深圳的关系，可以理解为：

> 深圳更偏产品、研发、品牌和市场，东莞更偏制造、交付和规模化生产。

### 佛山：工业、家电与建材

主题：**传统制造业如何形成产业集群**。

重点观察：

- 家电；
- 家具；
- 铝材；
- 建材；
- 智能制造；
- 工业自动化。

核心问题：

- 为什么家电、家具和建材企业会在佛山聚集；
- 产业链密度如何降低成本并提高交付速度；
- 传统制造企业如何从代工走向品牌。

### 中山：家电、照明与专业镇

主题：**专业镇经济与产业带协同**。

重点观察：

- 灯饰与照明；
- 小家电；
- 五金与配套；
- 区域品牌；
- 产业带电商。

核心问题：

- 为什么一个镇可以聚集完整产业链；
- 中小企业如何共享人才、供应商、物流和渠道；
- 专业镇模式的优势和风险是什么。

### 顺德：家电、餐饮与连锁品牌

主题：**制造能力与生活方式品牌化**。

重点观察：

- 家电产业；
- 餐饮；
- 连锁品牌；
- 地方消费文化；
- 产品品质与口碑传播。

顺德值得回答的核心问题是：

> 为什么广东餐饮和家电产业都能在这里形成强势品牌与长期口碑？

## 四、第三阶段：互联网与AI商业

推荐城市：**杭州**。

杭州代表的是互联网商业、电商生态和平台型增长。

重点观察：

- 阿里生态；
- AI 创业；
- 电商与内容商业；
- 平台、商家、服务商之间的关系；
- 数据、流量与交易如何协同。

与深圳对比：

- 杭州更接近互联网、电商和平台经济；
- 深圳更接近硬件、制造、跨境和科技创业。

## 五、第四阶段：ToB工业与工业软件

推荐路线：

> **苏州 → 昆山**

主题：**ToB、工业软件、机器人与自动化**。

重点观察：

- MES；
- ERP；
- PLM；
- 工业互联网；
- 机器人与自动化；
- 外资制造企业与本地供应链。

这条路线尤其适合 ToB 产品经理，用于理解：

- 软件如何嵌入真实生产流程；
- 企业客户为什么愿意付费；
- 工业项目为什么交付复杂、周期长；
- 标准化产品与定制化项目之间如何平衡。

## 六、第五阶段：内容、游戏与消费

推荐城市：**成都**。

成都代表：

- 内容；
- 游戏；
- 动漫；
- 消费；
- 直播；
- 短视频；
- MCN；
- IP 商业化。

如果未来研究抖音、TikTok、内容 IP 或达人生态，成都值得重点关注。

核心问题：

- 内容如何形成稳定转化；
- IP 如何从流量走向商品和长期品牌；
- 游戏、动漫、短视频与消费场景如何互相导流。

## 七、第六阶段：超级媒体与内容工业

推荐城市：**长沙**。

主题：**媒体、综艺、内容生产和大众传播**。

重点观察：

- 湖南广电生态；
- 综艺与内容制作；
- MCN 与达人；
- 文旅与城市品牌；
- 新消费与传播事件。

核心问题：

- 为什么长沙长期具备全国性内容影响力；
- 媒体资源如何带动消费、文旅和城市品牌；
- 内容如何被工业化生产并持续制造话题。

## 八、第七阶段：总部、政策与AI产业

推荐城市：**北京**。

北京更适合被视为商业和产业研究站，而不是单纯旅游城市。

重点观察：

- AI；
- ToB；
- 互联网总部；
- 政策与产业资源；
- 大型平台公司；
- 创业与资本网络。

代表性企业生态包括百度、字节跳动、美团、小米等。

核心问题：

- 总部型企业如何配置资源和组织复杂业务；
- 政策、资本、技术和人才如何相互影响；
- AI 产品如何从能力展示走向规模化商业场景。

## 十、四条长期学习路线

### 1. 供应链路线

> **义乌 → 东莞 → 佛山 → 中山 → 广州**

目标：理解产品如何被采购、制造、交付并进入渠道。

重点回答：

- 产品是如何被制造出来的；
- 供应链如何降低成本和试错门槛；
- OEM、ODM、品牌和渠道分别创造什么价值；
- 哪些环节最容易形成壁垒。

### 2. 科技路线

> **深圳 → 杭州 → 北京**

目标：理解技术和 AI 如何转化为商业结果。

重点回答：

- 技术如何找到付费场景；
- AI 如何创造收入或降低真实成本；
- 平台型、产品型和项目型商业模式如何区别；
- 技术公司如何形成规模化增长。

### 3. 内容与品牌路线

> **广州 → 成都 → 长沙**

目标：理解流量、IP、内容和品牌如何驱动消费。

重点回答：

- 内容如何转化为购买；
- 品牌如何获得溢价与复购；
- 达人、广告、直播和自然流量如何协同；
- IP 如何从一次爆款走向长期资产。

### 4. 全球化路线

> **深圳 → 香港 → 新加坡 → 日本（东京 / 大阪）→ 越南（胡志明市）**

目标：理解中国企业如何进入不同海外市场。

重点回答：

- 不同市场的消费者、渠道和监管差异；
- 本地化究竟涉及语言、产品、内容还是供应链；
- 中国企业如何建立海外销售、服务与品牌；
- 哪些能力可以跨市场复制，哪些必须本地重建。

## 十一、统一观察模板

每到一座城市，至少回答以下问题：

| 维度 | 观察问题 |
|---|---|
| 核心产业 | 这座城市最强的产业是什么 |
| 代表企业 | 龙头企业与典型中小企业分别是谁 |
| 商业驱动 | 主要由技术、供应链、渠道、品牌还是政策驱动 |
| 客户结构 | 本地、全国与海外客户分别占什么位置 |
| 获客方式 | 客户主要从哪里来 |
| 交付方式 | 产品或服务如何被交付 |
| 成本结构 | 最大成本来自制造、库存、流量、人力还是账期 |
| 增长方式 | 增长依赖扩品、扩渠道、扩区域还是提高复购 |
| 竞争壁垒 | 企业为什么不容易被替代 |
| AI 价值 | AI 是否真正改善收入、成本或交付效率 |
| 职业机会 | 哪类岗位和能力在当地更有价值 |
| 创业启发 | 哪些方向值得验证，哪些应明确排除 |

## 十二、长期更新原则

1. 每次游学、展会、产业园、工厂参访，都使用统一模板记录。
2. 区分事实、访谈观点、个人判断和待验证假设。
3. 不以“城市热闹”代替商业结论，不以个别成功案例代表整体行业。
4. 关注真实客户、收入、交付、成本、复购和现金流。
5. 每完成一条路线，都形成：
   - 城市对比；
   - 商业模式案例；
   - 机会地图；
   - 能力差距；
   - 下一步验证计划。

## 结语

真正值得期待的，不只是下一座城市，而是下一条学习主线。

当供应链、科技、内容、品牌和全球化几条路线被持续走访、记录和比较后，得到的就不只是旅行见闻，而是一套可以长期更新的商业地图。

以后遇到任何一个新行业，都可以更快判断：

- 它是供应链驱动、技术驱动、渠道驱动还是品牌驱动；
- 客户为什么付费；
- 企业如何交付；
- 利润来自哪里；
- AI 是否真正创造价值；
- 自己更适合进入哪一段价值链。
