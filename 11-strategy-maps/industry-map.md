# 产业与行业地图

## 1. 分层原则

建立行业知识时必须区分：

```text
产业 → 行业 → 品类 → 产品 → 产品系统 → 商业模式
```

例如：

```text
智能制造
→ 机器人
→ 割草机器人
→ RTK 割草机
→ 设备 + App + 云平台 + AI 售后
→ 硬件销售 + 配件 + 服务/订阅
```

## 2. 六大重点行业群

### A. 消费品

典型：美妆、服饰、家居、食品、宠物。

核心价值链：

```text
趋势/需求
→ 设计/选品
→ 供应链
→ 品牌
→ 内容/达人
→ 平台/零售
→ 履约
→ 复购
```

研究重点：品牌溢价、SKU 结构、内容转化、渠道效率、复购和库存。

### B. 消费硬件

典型：3C、AI硬件、智能家电、户外设备、可穿戴。

核心：

- ID/结构/电子/软件；
- BOM、模具、认证；
- OEM/ODM；
- App/云；
- 渠道和售后；
- 固件迭代和质量闭环。

商业模式可从一次性设备收入扩展到配件、耗材、云服务和 AI 能力。

### C. 智能装备与机器人

典型：服务机器人、割草机器人、清洁机器人、无人机、AMR、具身智能。

产业链：

```text
芯片/算力/模型
→ 感知传感器
→ 控制器/运动控制
→ 伺服/电机/减速器
→ 本体/结构
→ 操作系统/中间件
→ 算法/导航/规划
→ App/云/数据
→ 场景解决方案
→ 售后与运维
```

研究重点：硬件可靠性、算法能力、量产成本、场景闭环、服务网络和数据飞轮。

### D. 工业制造

典型：工业自动化、机床、仪器、零部件、工业软件、机器视觉。

客户更关注：

- OEE；
- 良率；
- 停机；
- 节拍；
- 人力；
- 能耗；
- 质量追溯；
- ROI；
- 稳定性。

商业链通常是：

```text
销售/代理
→ 售前
→ 方案
→ POC/测试
→ 项目
→ 安装调试
→ 验收
→ 维保/备件
```

### E. 数字产品与 AI

典型：SaaS、ERP、CRM、AI Agent、数据平台、MaaS。

研究重点：

- ICP；
- Workflow；
- 数据接入；
- 权限；
- 集成；
- 价值证明；
- CAC/LTV；
- NRR；
- AI 推理成本；
- 产品化 vs 项目化。

### F. 内容、游戏与 IP

典型：游戏、动漫、短视频、虚拟形象、文旅 IP。

价值链：

```text
创意/IP
→ 内容生产
→ 平台发行
→ 用户增长
→ 社区/运营
→ 广告/内购/订阅
→ 商品/授权/线下体验
```

研究重点：内容生命周期、用户留存、全球发行、本地化、IP 衍生和品牌资产。

## 3. 行业研究十二问

1. 行业解决什么核心问题？
2. 市场处于导入、增长、成熟还是衰退？
3. 客户是谁？
4. 购买触发是什么？
5. 价值链有哪些环节？
6. 谁拿走利润？
7. 龙头依靠什么壁垒？
8. 产品标准化程度如何？
9. 销售和交付复杂度如何？
10. 监管/认证/资本要求是什么？
11. AI/技术正在改变哪个环节？
12. 中国企业全球化的优势和短板是什么？

## 4. 行业利润池

不要只看市场规模，还要看 Value Pool：

- 高毛利零部件；
- 核心软件；
- 品牌；
- 渠道；
- 售后；
- 耗材；
- 数据；
- 金融；
- 平台抽成。

同一个产业链中，收入最大的环节不一定利润最好。

## 5. 行业进入评分

推荐维度：

- 市场增长；
- 利润池；
- 客户痛点；
- 产品能力匹配；
- 供应链优势；
- 销售周期；
- 资本要求；
- 合规门槛；
- 全球化空间；
- AI 改造空间；
- 个人/团队可进入性。

## 6. Industry × City

行业研究应与城市节点连接：

- 深圳：消费电子、AI硬件、无人机、机器人、芯片、跨境；
- 广州：内容游戏、跨境、汽车、机器人、消费品牌；
- 东莞：电子制造、OEM/ODM、自动化；
- 佛山/顺德：家电、家具、装备、工业；
- 苏州/无锡/常州：工业自动化、机器人、新能源、工业软件；
- 杭州：电商平台、SaaS、AI、数字商业；
- 北京：AI、科研、总部、平台、自动驾驶；
- 上海：总部、企业服务、金融、汽车、品牌与国际业务。

城市不是标签，后续应持续用企业、展会、工厂、客户访谈和数据验证。

## 7. Industry × AI

分析 AI 时不要问“这个行业能不能用 AI”，而要问：

- 哪个岗位有高频信息任务？
- 哪个决策依赖大量非结构化信息？
- 哪个流程有重复判断？
- 哪个环节数据已经存在？
- 哪个业务结果可以量化？
- Agent 建议和 Workflow 执行如何分工？
