# 11｜战略总地图 Strategy Maps

本模块把知识库从“很多专题文档”收敛为可导航的全局认知系统。

## 六张总地图

1. **产业地图**：哪些产业、行业和价值链值得研究。
2. **地区地图**：中国城市产业节点与全球国家市场。
3. **产品地图**：实体产品 + 数字产品 + 服务产品 + 产品线经营。
4. **增长地图**：品牌、内容、广告、达人、平台、销售和渠道。
5. **生态链地图**：供应商、制造商、品牌、平台、服务商、客户如何连接。
6. **AI Business OS 地图**：业务 → 系统 → 数据 → 知识 → Workflow → Agent → 决策。
